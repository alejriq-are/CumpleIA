# F1.24G — Preflight Devstral Small 2 24B

**Fecha:** 2026-09-08  
**Estado:** CERRADO — CANDIDATO NO SELECCIONADO

## 1. Objetivo

Evaluar Devstral-Small-2-24B-Instruct-2512 como posible candidato local de mayor capacidad para CumpleIA.

La evaluación mantiene como criterios principales:

1. capacidad de coding y comportamiento agentic;
2. compatibilidad potencial con Claude Code;
3. viabilidad operacional en el notebook de benchmark;
4. rendimiento suficiente para una corrida funcional con límite de 1800 segundos.

El candidato solo debía avanzar a las etapas de SRT, contextos superiores y prueba funcional RAT si superaba previamente los gates operacionales y de rendimiento.

## 2. Hardware y entorno

Equipo de benchmark:

- GPU: NVIDIA GeForce RTX 5060 Laptop GPU;
- VRAM: 8151 MiB;
- RAM física: 32 GB;
- WSL: Ubuntu 24.04;
- llama.cpp commit: `b95502ba9aa0eb73a2f4fc8878d7fbe6a847a0b9`;
- llama.cpp versión reportada: `0.1.2-dev`, commit `b95502b`;
- backend CUDA habilitado.

Durante el preflight se detectó que WSL exponía inicialmente aproximadamente 16 GiB de RAM.

Se configuró posteriormente:

    [wsl2]
    memory=24GB

Después del reinicio, WSL reportó aproximadamente:

- RAM total: 23 GiB;
- RAM disponible en reposo: 21 GiB;
- swap: 6 GiB.

La repetición del gate 8K se realizó después de esta corrección.

- prompt throughput: 16.71 tok/s;

## 10. Evaluación de rendimiento

Las mediciones definitivas posteriores a la corrección de WSL fueron aproximadamente:

- 0.546 tok/s;
- 0.543 tok/s.

Por lo tanto, el aumento de RAM disponible para WSL no produjo una mejora material en la velocidad de generación.

A aproximadamente 0.54 tok/s, el máximo teórico de generación continua durante 1800 segundos sería inferior a 1000 tokens, sin considerar:

- prefill;
- múltiples turnos;
- tool calls;
- lectura de archivos;
- edición de código;
- ejecución de comandos;
- verificaciones del agente.

Este rendimiento es insuficiente para una corrida funcional agentic del benchmark CumpleIA dentro del presupuesto temporal establecido.

## 11. Gates no ejecutados

Debido al fallo del gate de rendimiento 8K, no corresponde ejecutar:

- Claude Code/SRT;
- 16K;
- 24K;
- prefill limpio 24K;
- 32K;
- corrida funcional RAT.

Esto evita consumir tiempo y generar evidencia funcional que no sería comparable de manera útil debido a la limitación operacional ya demostrada.

No se selecciona como reemplazo del candidato local actual.

## 13. Hallazgo adicional del entorno

Durante F1.24G se identificó que WSL disponía inicialmente de aproximadamente 16 GiB de los 32 GB físicos del equipo.

Se aumentó la asignación a 24 GB.

Este cambio se mantiene para evaluaciones locales posteriores y debe considerarse parte del entorno a partir de F1.24G.

Los resultados históricos anteriores permanecen válidos como evidencia de las condiciones existentes en el momento de sus respectivas ejecuciones y no se repiten.
