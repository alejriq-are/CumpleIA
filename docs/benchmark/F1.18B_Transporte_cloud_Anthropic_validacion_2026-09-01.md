## 1. Objetivo

Validar el transporte cloud real de Claude Code hacia Anthropic dentro del entorno controlado del Benchmark RAT, manteniendo las restricciones de red y capacidades establecidas en F1.16 y F1.17.
La validación debe demostrar simultáneamente que:

- Claude Code puede realizar una inferencia real utilizando el backend Anthropic;
- únicamente los dominios necesarios de Anthropic permanecen accesibles;
- Internet general continúa bloqueado dentro de SRT;
- las restricciones de Managed Settings continúan vigentes;
- no se exponen ni registran credenciales;
- no se modifica todavía el transporte destinado a backends locales.
