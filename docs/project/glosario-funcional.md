# Glosario funcional de CumpleIA

Referencia: 29/10/2026, base publicada `41c561b`. Uso en la navegación conectada; no fija criterios jurídicos. Conserva los identificadores G01–G30 del [análisis de propuestas](evaluacion-propuestas-claude.md). Las equivalencias históricas explican rótulos anteriores sin renombrar contratos ni registros.

| Referencia | Concepto y uso aceptado | Diferencia que debe conservarse |
| --- | --- | --- |
| G01 | Consultar: leer información, por ejemplo Consultar última determinación guardada. | No se reemplaza globalmente por Ver. Consultar no guarda. |
| G02 | Revisión de aplicabilidad, revisión documental y revisión del RAT llevan su objeto. | Revisión no se reserva exclusivamente al circuito formal documental. |
| G03 | Cambios sin guardar, consultando, error y Pendiente de analizar describen situaciones distintas. | Pendiente de analizar es un resultado de aplicabilidad, no un error de red. |
| G04 | Resultado de la revisión documental registra una observación. Decisión de la organización registra su posición mediante persona facultada. | Ninguno modifica por sí solo el original; no son sinónimos. |
| G05 | Versión documental registrada de infancia: registro histórico conservado. | Equivale al antecedente llamado resolución documental; su número e identidad no cambian por el rótulo. |
| G06 | Preparar nueva versión a partir de esta copia contenido temporalmente; Registrar nueva versión crea el registro. | Copiar y previsualizar no registran. |
| G07 | Nombre de la edición (texto libre): texto opcional para reconocer la preparación o documento. | Antes Etiqueta; no es Identificador de versión. Referencia, identificador interno y número de versión son distintos. |
| G08 | Guardar o Registrar se acompaña del objeto. | Guardar EIPD actualiza; guardar determinación agrega una revisión; registrar versión de infancia agrega otro documento histórico. |
| G09 | Borrador: estado de preparación, que puede estar guardado. | No significa necesariamente sin guardar ni utiliza una convención automática de versiones menores. |
| G10 | Evaluación versión N y estado: identidad y situación de una evaluación. | No es versión documental N. Confirmado en el modelo de evaluación no significa EIPD aprobada o activada. |
| G11 | Asociación actual o histórica describe relación con material/contexto. Facultad vigente o revocada describe habilitación documental. | Un antecedente desactualizado no se borra ni se convierte en una facultad. |
| G12 | Acepta, Rechaza y Requiere cambios son decisiones documentales de organización. | Acepta el documento no confirma ni activa EIPD. |
| G13 | Historial de determinaciones, versiones, revisiones o facultades identifica el objeto consultado. | La lista disponible no representa una auditoría completa del expediente. |
| G14 | Expediente documental: documentos y antecedentes vinculados a una evaluación. | No promete un paquete íntegro ni una verificación de vigencia de todo su contenido. |
| G15 | Documentos guardados es el destino de consulta; Revisar y decidir es la agrupación. | Abrir el destino no emite una revisión. |
| G16 | Evaluación de licitud analiza base y fundamento; EIPD documenta impacto; valoración de riesgos registra probabilidad, impacto y fundamentos. | Son objetos relacionados, no tres nombres del mismo formulario. |
| G17 | Inventario de tratamientos es el listado; actividad de tratamiento es un registro. | RAT puede referirse al registro de actividades; no toda mención significa una única actividad. |
| G18 | Anexo de respaldo es un archivo asociado. Fuentes y evidencias es una sección de análisis documental. | Adjuntar un archivo no demuestra suficiencia de evidencia ni eficacia del control. |
| G19 | Cambiar contexto selecciona trabajo existente y Aplicar contexto lo activa en esa pestaña. | No crea evaluación, no guarda pendientes ni sincroniza las demás ventanas. |
| G20 | Determinar aplicabilidad registra por separado si corresponde EIPD e infancia y sus fundamentos. | Los accesos dependen de lo guardado y asociado; el título no equivale a una decisión jurídica automática. |
| G21 | Fundamento explica el análisis de la conclusión o actuación. Motivo del cambio explica una modificación. | Fundamento no se reserva exclusivamente a la base de licitud ni se sustituye siempre por motivo. |
| G22 | Solo lectura indica que la vista no permite editar, con la razón correspondiente. | Puede depender de vista, rol, estado o material; no atribuir siempre el bloqueo al rol. |
| G23 | Facultad documental habilita actuaciones de organización sobre el material admitido. | Permiso de aplicación o ser administrador no concede esa facultad. Un UUID identifica; no representa el nombre de la persona. |
| G24 | Describir riesgos identifica daño y análisis; valorar riesgos aplica la metodología; medidas buscan mitigarlo; residual es el riesgo tras las medidas. | La matriz cualitativa actual es interna y fija; el nivel no aprueba ni activa EIPD. |
| G25 | Tratamiento: uso u operación sobre datos; finalidad: para qué; titular: persona a quien conciernen; responsable y encargado: roles declarados; base: propuesta de sustento; transferencia: comunicación en su contexto. | Son ayudas funcionales. La guía no sustituye su definición normativa ni valida la calificación declarada. |
| G26 | RAT: Registro de Actividades de Tratamiento. EIPD: evaluación de impacto en protección de datos personales. LIA: análisis de interés legítimo. | Expandir siglas orienta al usuario; no garantiza que todo el formulario o criterio jurídico esté integrado. |
| G27 | Resultado del autodiagnóstico procede del cuestionario real de 50 preguntas. | No confundir con el resultado ilustrativo de la maqueta ni prometer un informe/exportación inexistente. |
| G28 | Panel principal orienta y permite continuar; Menú cambia módulos; Secciones abre destinos del módulo. | Continuar retoma una ubicación recordada, no impone un circuito jurídico. |
| G29 | Descarga JSON ofrece el contenido e índice disponibles. Los archivos se descargan por separado. | No prometer exportaciones Word/PDF desde la aplicación por existir guías externas en esos formatos. |
| G30 | FICTICIA, SIMULADA y pruebas de desarrollo identifican el piloto. | No eliminar estas marcas para aparentar operación productiva; los antecedentes históricos conservan su identidad. |

## Identidades que pueden coexistir

Una evaluación puede ser versión 1 en borrador, tener revisión de aplicabilidad 6 y contener versiones documentales de infancia 1 y 2. Cada una de esas versiones puede tener revisiones y decisiones propias. El nombre libre PRUEBA-1 no convierte ninguno de esos números en 1 ni los vincula automáticamente.
